# Cyber Security Lab Resources #
## Purpose ##
This repository hosts the files and resources used to develop student lab activities for cybersecurity training. These labs focus on penetration testing, event detection and analysis, and incident response.

## Overview ##

This repository is designed to support the creation, delivery, and maintenance of hands-on labs for Certificate IV in Cyber Security and related training. The materials here may include:
- Lab instructions and walkthroughs
- Configuration files and scripts
- Virtual machine setup notes
- Sample logs and datasets
- Supporting documentation
